# Character Sticker Engine 企画書 v0.1

更新日: 2026-10-07

## 1. 企画概要

Character Sticker Engine は、1体のキャラクターについて用意された正本資料を入力として、LINEスタンプの商品企画から制作・検品・公開準備までを半自動化する汎用制作エンジンである。

最初の実証対象は「うたたねちゃん」。ただし設計の中心はキャラクターではなく、**キャラクターを差し替えて再利用できる制作工程**に置く。

## 2. 背景

キャラクタースタンプ制作には、キャラクター造形の維持、台詞選定、ポーズ設計、画像制作、透過・サイズ調整、ファイル命名、LINE仕様チェック、商品情報入力、審査申請など多数の工程がある。

生成AIだけに任せると、ポーズごとに顔・輪郭・色・体格が変わる「作画崩壊」が起きやすい。一方、工程を完全手作業にするとキャラクターを増やすたびに同じ作業を繰り返す。

そこで、キャラクター固有部分を Character Pack として標準化し、商品企画・規格化・検品・公開準備をエンジン化する。

## 3. プロダクトビジョン

理想の操作は次の通り。

1. キャラクターの正本画像・三面図・設定を登録する。
2. 「LINEスタンプ16個を作る」を選ぶ。
3. エンジンが会話用途の構成、台詞、感情、ポーズ案を作る。
4. Character Reference に拘束した素材制作を行う。
5. LINE仕様に合わせて画像を自動整形する。
6. 構成・視認性・ファイル仕様・禁止事項候補を自動検品する。
7. 商品情報とアップロード素材をまとめる。
8. 人間が最終プレビューを承認する。
9. Creators Marketへの登録・審査申請・公開へ進む。

目標UXは「大量生成」ではなく **キャラクター品質を保ったワンクリック出版**。

## 4. 対象ユーザー

- 自作キャラクターを持つ個人クリエイター
- 複数キャラクターを展開する小規模チーム
- キャラクターIPをLINEスタンプへ展開したい制作者
- AI画像生成を使いたいが、キャラの一貫性と審査事故を避けたいユーザー

## 5. MVP

PoC①では静止画スタンプ16個を対象とする。

実装対象:
- Character Pack読込
- 16個の商品構成生成
- communication tagによる用途配分
- 台詞・感情・ポーズ定義
- 画像素材の受け入れ
- PNG透過・サイズ・余白・RGB・容量等の検査
- main / tab / sticker画像の出力
- ファイル命名
- 商品メタデータ生成
- プレビュー用一覧生成
- Creators Market登録用成果物の生成

PoC①では自動化しない:
- 審査通過の保証
- 人間による著作権・商標権判断の完全代替
- 人間確認なしの審査申請・公開
- あらゆる画像生成サービスへの依存固定

## 6. 商品設計思想

第1弾は「かわいさ」だけでなく「使われること」を優先する。

初期ヒューリスティック:
- 約50%: 日常返答・挨拶
- 約25%: 感情・リアクション
- 約25%: キャラクター固有の仕草・ネタ

特に acknowledge（OK/了解）を必須カテゴリとする。その他、thanks / greeting / apology / positive / encouragement / surprise / character を基本カテゴリとする。

この比率は固定仕様ではなく、販売・送信データやキャラクター特性に応じて変更可能な Strategy とする。

## 7. うたたねちゃん第1弾の仮コンセプト

**「毎日使える、ちょっと眠そうなペンギン」**

実用品として成立する基本表現に、寝落ち・覗き込み・脱力など、うたたねちゃん固有の挙動を混ぜる。

PopMate版で確立した仕草やCharacter Referenceを再利用可能な入力資産として扱い、LINE版でキャラクターを描き直さない。

## 8. 将来展開

Phase 1: 静止画スタンプ16個
Phase 2: 静止画8/24/32/40個への一般化
Phase 3: アニメーションスタンプ
Phase 4: メッセージ・カスタム・BIG等へのplatform profile追加
Phase 5: Creators Market登録支援のブラウザ自動化
Phase 6: 販売後データを次セットの商品企画へフィードバック
Phase 7: LINE以外のステッカー/絵文字プラットフォームへのadapter追加

## 9. 成功条件

PoC成功条件は「うたたねちゃんのスタンプが作れた」ではない。

**別キャラクターの Character Pack を投入し、エンジン本体を変更せずに別の商品セットを生成できること。**

ここを満たして初めて Character Sticker Engine とする。
