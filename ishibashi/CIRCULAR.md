# Character Sticker Engine 回覧板

このファイルは **CHAPPY ↔ ISHIBASHI（将来は他AIも参加可）間の追記専用ログ** です。

## 絶対ルール

- 既存の回覧本文を削除・改変・並べ替えしない。
- 新しい連絡は必ず末尾へ追記する。
- 訂正が必要な場合も過去を直さず、新しい項目として訂正を書く。
- 各項目には連番ID、日時、FROM、TO、種別、関連IDを付ける。
- `CURRENT_TASK.md` は「現在の正式指示」、この回覧板は「そこへ至った経緯と応答の正史」とする。
- 実装仕様の正本は `specs/`、企画・調査の正本は `docs/`。回覧板へ仕様全文を重複コピーしない。

## 種別

- `指示` : 新規タスク・追加指示
- `報告` : 作業結果・確認結果
- `質問` : 判断が必要な事項
- `回答` : 質問への回答
- `決定` : 方針確定
- `訂正` : 過去記録の訂正（元記録は残す）
- `保留` : 今は実施しない事項

Character Sticker Engine の初期企画・仕様をGitHubへ整理した。

目的は、うたたねちゃんLINEスタンプを最初の実証例としつつ、別キャラクターでも Character Pack の交換によって再利用できる汎用エンジンを構築すること。

現在は **PLANNING / DO NOT IMPLEMENT YET**。
マスコット版うたたねちゃん（PopMate）が一区切りし、ユーザーから明示的な着手指示が出るまでは実装しないこと。

開始時の現在指示は `CURRENT_TASK.md` を参照。
固定実装原則は `IMPLEMENTATION_RULES.md` を参照。
企画・仕様・調査資料は `docs/`、`specs/`、`examples/` を参照。

### 初期設計上の重要決定

1. エンジンは「うたたねちゃん」を知らない構造にする。
2. キャラクター固有情報をエンジンへハードコードしない。
3. コードでキャラクターを再描画しない。正本素材を扱う。
4. PoC①はローカル生成・検品・preview・packageまでを対象とする。
5. Creators Marketへの申請・公開はPoC①の対象外。
6. 2体目のCharacter Packで再利用性を確認して初めて汎用化成功とみなす。
